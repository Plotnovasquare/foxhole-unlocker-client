## 🧩 About

**Foxhole Unlocker Client** is a curated list of Foxhole open-source tools:

- **Overlays** — on-screen helpers, map markers, resource trackers, HUD notes
- **Quality-of-Life Helpers** — inventory manager, quick-craft notes, logi route planner
- **Research Notes** — front-line layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### ESP
- Map Overlay — real-time position and markers
- Resource Tracker — track scrap, components, and supplies
- Inventory Manager — quick-transfer and sorting notes
- HUD Customization — hide or rearrange UI elements for clarity

### Wallhack
- Player Radar — directional awareness for study (single-player only)
- Loot Highlighter — highlight nearby items and crates
- Distance Markers — display distances to key points

### Aimbot
- Auto-Enter Notes — streamline vehicle entry and exit
- Quick Map Ping — mark locations for convoy planning
- Config Profiles — save and load custom settings
